# Template Baukasten

Ein interaktives Werkzeug zur **systematischen Erstellung wiederverwendbarer Prompt‑Templates** für den Einsatz mit großen Sprachmodellen (LLMs) und Entwicklungs‑Workflows wie GitHub Copilot.

Dieses Projekt bietet eine modulare Struktur von Bausteinen, um komplexe Prompts in klar definierte, wiederverwendbare Komponenten zu zerlegen und als strukturierte Anleitung oder Vorlage zu nutzen.

---

## 🧠 Motivation

Viele KI‑Abfragen und Prompt‑Setups werden ad hoc erstellt und sind schwer wiederholbar oder wartbar.  
Der **Template Baukasten** hilft dabei, diese Prompts in **übersichtliche, logisch strukturierte Templates** zu überführen, die:

- wiederverwendbar sind  
- leicht angepasst werden können  
- dokumentiert und exportiert werden können  

---

## 🚀 Features

- 📦 Bausteinbasierte Prompt‑Struktur  
- 📄 Ausgabe als Markdown‑ oder Baumstruktur  
- 💾 Speichern und Laden von Templates  
- 🧩 Kombination mehrerer Komponenten  
- 🛠 GUI‑Interface zur einfachen Nutzung
